# English Path — английский с нуля до C2

Интерактивный сайт для **самостоятельного** изучения английского: от первых фраз (A0) до свободного владения (C2). Программа построена по CEFR: Level → Unit → Lesson.

Это кликабельный прототип на чистых HTML, CSS и JavaScript, без сборки и сервера. Прогресс хранится в браузере (localStorage).

## Что внутри

- **Урок из 7 шагов:** теория (объяснение на русском, примеры на английском) → видеоурок → видео по уровню (цели и can-do) → лексика (IPA, озвучка, перевод) → упражнения (выбор, вставка, аудирование, перевод, порядок слов) → Quiz с объяснением ошибок → Speaking / Writing с отправкой ИИ или преподавателю.
- **Личный кабинет:** XP, серия дней, дневная цель, «Продолжить», рекомендации по слабым местам, достижения.
- **Интервальное повторение (SM-2)** слов и грамматических правил.
- **Погружение:** тексты с озвучкой и двойными субтитрами, видео, подкасты, сериалы по уровням.
- **Входной тест** и открытие курса с подходящего уровня.
- **ИИ-тьютор (демо)** в контексте урока.

## Запуск локально

```bash
python -m http.server 8765
```

Затем откройте `http://localhost:8765`.

Видео встраиваются с YouTube официальным способом (youtube-nocookie.com) и принадлежат их авторам.
